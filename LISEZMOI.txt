EN CAVALE — serveur multijoueur
================================

1. Lance l'exécutable (Windows : double-clic ; Mac / Linux : ./encavale-server-… dans un terminal).
   Au premier lancement, un fichier config.json est créé à côté : nom, port, mot de passe,
   nombre de joueurs, code admin… Modifie-le puis relance le serveur.

2. Les joueurs te rejoignent avec l'adresse affichée :
     - sur ton PC         : http://localhost:7777
     - sur ton réseau     : http://192.168.x.x:7777
     - depuis Internet    : http://TON-IP-PUBLIQUE:7777 (il faut ouvrir le port 7777 TCP sur ta box)
   ou depuis le site du jeu : bouton MULTIJOUEUR, puis l'adresse.

3. Dans le jeu, tape /admin TON-CODE dans le chat pour lancer les manches, régler la partie,
   expulser ou bannir. Dans ce terminal, tape « aide » pour toutes les commandes.

Mac : si macOS bloque le fichier (« développeur non identifié »), clic droit > Ouvrir,
ou dans un terminal : xattr -d com.apple.quarantine encavale-server-*
Windows : si SmartScreen s'affiche, « Informations complémentaires » > « Exécuter quand même ».

Tout le reste : https://github.com/axizof/encavale-server
