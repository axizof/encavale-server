EN CAVALE — serveur multijoueur
================================

1. Lance l'exécutable (Windows : double-clic ; Mac / Linux : ./encavale-server-… dans un terminal).
   Au premier lancement, un fichier config.json est créé à côté : nom, port, mot de passe,
   nombre de joueurs, mot de passe du panneau… Modifie-le puis relance le serveur.

2. Les joueurs te rejoignent avec l'adresse affichée :
     - sur ton PC         : http://localhost:7777
     - sur ton réseau     : http://192.168.x.x:7777
     - depuis Internet    : http://TON-IP-PUBLIQUE:7777 (il faut ouvrir le port 7777 TCP sur ta box)
   ou depuis le site du jeu : bouton MULTIJOUEUR, puis l'adresse.

3. Tu administres le serveur depuis ce terminal (tape « aide ») ou depuis le panneau web, sur
   ce PC : http://localhost:7777/admin, avec le mot de passe « panelPassword » affiché au
   démarrage. Réglages, lancement des manches, arrivées, expulsions, bannissements, stats.
   Tu peux aussi nommer des admins en jeu, seulement des comptes Discord vérifiés :
   « admin <joueur> » dans ce terminal, ou le bouton ☆ Admin du panneau.

Mac : si macOS dit que le fichier est « endommagé » ou vient d'un « développeur non identifié »,
c'est normal (exécutable non signé par Apple). Dans un terminal, dans le dossier :
  xattr -dr com.apple.quarantine .
Windows : si SmartScreen s'affiche, « Informations complémentaires » > « Exécuter quand même ».

Tout le reste : https://github.com/axizof/encavale-server
